🎯 快速开始（3步）
═══════════════════════════════════════════════════════════════════════════════

步骤1 - 安装：
  cd python
  python -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt

步骤2 - 配置：
  cp .env.example .env
  vi .env  # 填写 GATE_API_KEY, GATE_API_SECRET, OPENAI_API_KEY

步骤3 - 运行：
  python main.py
  # 访问: http://localhost:3100
